主题切换原理解析

1

CSS 变量定义

在 :root 中定义亮色主题变量，在 [data-theme="dark"] 中定义暗色主题变量。所有颜色通过变量引用，实现一处修改全局生效。

:root { --bg-primary: #ffffff; --text-primary: #1e293b; } [data-theme="dark"] { --bg-primary: #0f172a; --text-primary: #f1f5f9; }
2

data-theme 属性切换

通过在 <html> 标签上设置 data-theme 属性，CSS 选择器会自动匹配并应用对应的主题变量值。

// 亮色主题 <html data-theme="light"> // 暗色主题 <html data-theme="dark">
3

localStorage 持久化

用户切换主题时，将选择保存到 localStorage。下次访问时优先读取保存的值，实现主题偏好记忆功能。

// 保存主题 localStorage.setItem('theme', 'dark'); // 读取主题 const saved = localStorage.getItem('theme');
4

系统主题检测

首次访问时，使用 matchMedia 检测系统是否偏好暗色模式，自动适配用户的系统设置。

const prefersDark = window.matchMedia( '(prefers-color-scheme: dark)' ).matches;
5

JavaScript 交互逻辑

监听切换按钮点击事件，读取当前主题状态，切换后更新 DOM 属性并保存到 localStorage，完成整个交互闭环。

themeToggle.addEventListener('click', () => { const current = html.getAttribute('data-theme'); const newTheme = current === 'dark' ? 'light' : 'dark'; setTheme(newTheme); });
6

平滑过渡动画

为 body 和相关元素添加 CSS transition 属性，主题切换时颜色会平滑过渡，提升用户体验。

body { transition: background-color 0.3s ease, color 0.3s ease; }
